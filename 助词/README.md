# 助词

## 格助詞

格助词之所以叫做格助词 ，是通过格助词来判断前面接续的体言（名词，代词，数词）属于哪一格，也就是判断名词在句子中属于哪些成分。

| 类型 | 说明 | 助词 |
| --- | --- | --- |
| 主格助词 | 表示主语 | [が](./助词/が.md)、[の](./助词/の.md)（定语从句主语） |
| 领格助词 | 表示所属 | [の](./助词/の.md)、[が](./助词/が.md)（我が国等短语） |
| 宾格助词 | 表示宾语 | [を](./助词/を.md)（他动词施动对象）、[が](./助词/が.md)（表示情感能力的形容词的对象）等|
| 补格助词 | 表示补语, 类似于英语中的状语，表示时间，地点，方式，原因等等 | [から](./助词/から.md)、[で](./助词/で.md)、[と](./助词/と.md)、[に](./助词/に.md)、[へ](./助词/へ.md)、[を](./助词/を.md)、[まで](./助词/まで.md)、[より](./助词/より.md)|

## 接續助詞

接续助词和格助词不一样，前面是接续体言（动词，形容词，形容动词）的，如果要接续名词也是要以助动词です的变形进行接续。主要用于句子和句子的连接。接续助词也分三种。

| 类型 | 说明 | 助词 |
| --- | --- | --- |
| 顺接 | 表示前项是原因、理由或条件，后项是顺理成章、意料之中的结果或结论。 |`て`（因果/动作先后）、`から`、`ので`、`ば`、`と`、`たら` |
| 逆解 | 表示转折或让步。前项和后项的逻辑相反，即：前项是某种情况，但后项产生的结果却出乎意料，或者与常规逻辑相反（“虽然……但是……”）。 |`が`、`のに`、`けど`、`ても（でも）`、`ては`、`くせに`、`ものの` |
| 并列 | 表示平铺直叙、动作的连续、同时进行，或是列举并列的事物/状态，前后项没有明显的因果或转折关系。 | `ながら`、`で`、`が`、`て`（表示并列或动作先后）、`し`（列举理由/特点）|

## 副助詞\提示助词

| 类型 | 说明 | 助词 |
| --- | --- | --- |
| 提示助词 | 提示助词接在句子成分后，提示强调该成分或增添某种语法意义。提示助词也是日语中最富于色彩的部分之一，不仅可以接续在体言后也可以接续在用言后面。 |`は`、`も`、`でも`、`しか`、`こそ`、`さえ`、`すら`|
| 副助词 | 和名字一样，有着副词意思的助词。有些语法书中也将提示助词和副助词画上等号。接续和提示助词一样，体言和用言都可以接续。 |`だけ`、`ほど`、`ばかり`、`ぐらい`、`ずつ`|

## 終助詞\并列助词

| 类型 | 说明 | 助词 |
| --- | --- | --- |
| 并列助词 | 提示助词接在句子成分后，提示强调该成分或增添某种语法意义。提示助词也是日语中最富于色彩的部分之一，不仅可以接续在体言后也可以接续在用言后面。 |`と`、`たり`、`とか`、`や`、`に`|
| 终助词 | 终助词是接续在句子结尾的助词，通常表示某种语气和身份。 |`か`、`ね`、`よ`、`わ`、`かな`、`かしら`，`ぞ`|
